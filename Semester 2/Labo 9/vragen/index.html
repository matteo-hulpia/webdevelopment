Demo Session Storage

Data blijft niet behouden als het tabblad gesloten wordt (behalve met ctrl+shift+t).

Data blijft behouden als de pagina herlaad.

Data wordt niet gedeeld over meerdere tabs.

Als je een andere url opent kan deze enkel aan de sessie data als deze op hetzelfde domein zit.

Demo Local Storage

Data behouden als tab gesloten wordt en opnieuw geopend.

Data behouden als pagina herladen wordt.

Data behouden als browser afgesloten wordt.

Data niet behouden als de pagina in een andere browser geopend wordt.

Data wordt gedeeld als je pagina in 2 tabs opent.

Andere url kan niet aan die data.
